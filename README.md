## ระบบที่ช่วยให้จำได้จริง

- **Daily Review** — ทบทวนแบบเว้นระยะ (Leitner) นัดคำแต่ละคำหลัง 1, 2, 4, 7, 14 วัน
- **ลองอีกครั้งเมื่อตอบผิด** — ปิดตัวเลือกที่ผิด ให้ลองใหม่ 1 ครั้ง (นับคะแนนเฉพาะครั้งแรก)
- **เสียงครูผู้หญิง** — ออกเสียงแบบโฟนิกส์ ปรับความเร็วได้ 4 ระดับทุกหน้าจอ · “Say it with me” ให้เด็กพูดตาม
- **อังกฤษเป็นหลัก** — คำแปลไทยเปิดเมื่อต้องการด้วยปุ่ม EN / ไทย

## วิธีใช้งาน

**บนเว็บ (แนะนำ)** — เปิดลิงก์ GitHub Pages ด้วย Safari (iPad/iPhone) หรือ Chrome (Android)
แล้วกด **แชร์ → Add to Home Screen** จะได้ไอคอนแมวส้มเหมือนแอปจริง และใช้ออฟไลน์ได้หลังเปิดครั้งแรก

**เป็นไฟล์** — ส่ง `Milin-English-Club.html` เข้าเครื่อง (AirDrop / iCloud Drive) แล้วเปิดด้วย Safari

แตะหน้าจอ 1 ครั้งเพื่อเปิดเสียง (ข้อกำหนดของ iOS)

### เปิด GitHub Pages (ครั้งเดียว)
1. Settings → General → Danger Zone → **Change visibility → Public**
   (repo มีเฉพาะโค้ดที่เขียนเอง ภาพชีทลิขสิทธิ์ไม่ได้อัปโหลด)
2. Settings → **Pages** → Branch `main` / `(root)` → Save

### อัปเดตหลังแก้ไข
```bash
git add -A && git commit -m "update" && git push
```
ถ้าแก้ไฟล์แอป ให้เปลี่ยน `VERSION` ใน `sw.js` ด้วย เพื่อให้เครื่องที่ติดตั้งไว้ดึงเวอร์ชันใหม่

## โครงสร้างไฟล์

```
Milin-English-Club.html   แอปทั้งหมด (HTML + CSS + JS + ฟอนต์ฝังในไฟล์)
                          ลิงก์ตรงไปยังบทเรียน: #exam  #unit=u3  #drill=blank  #grammar=g2  #spell=u4  #mock  #skills  #skills=test  #skills=s4listen
index.html                หน้าแรกของเว็บ → เปิดแอป
manifest.webmanifest      ข้อมูลสำหรับ Add to Home Screen
sw.js                     ใช้งานออฟไลน์ (service worker)
icons/                    ไอคอนแอป
LEARNING-DESIGN.md        หลักการเรียนรู้และงานวิจัยอ้างอิง
```

ภายในไฟล์แอป แบ่งส่วนด้วยคอมเมนต์:

| ส่วน | หน้าที่ |
|---|---|
| 1. CSS | ระบบดีไซน์ v3 (สี · ฟอนต์ Lexend / Andika / IBM Plex Sans Thai Looped · เลย์เอาต์ iPad/มือถือ) |
| 2. CONTENT | เนื้อหาจากชีท 39 ใบ (โฟนิกส์ เรื่องอ่าน เกม) |
| 2B. หลักสูตรสอบ | `UNITS` `BONUS` `BLANKS` `GRAMMAR` `PASSAGES` `ODD` `TRICKY` `MISTAKES` |
| 3–4. PHONICS / VOICE | ตารางเสียง + เสียงครูผู้หญิง |
| 5. CORE | state, ความคืบหน้า, ทบทวนเว้นระยะ, เมนู |
| 6A–6I | หน้าหลัก · คำศัพท์ · Quiz engine · ข้อสอบ · ไวยากรณ์ · สะกดคำ · จับคู่ · หมวด · ผู้ปกครอง |
| 6. GAMES | เกมเดิม 15 เกม |

**เพิ่มคำศัพท์:** เพิ่มใน `UNITS[n].words` รูปแบบ `{w, th, e (emoji) หรือ svg, s (ประโยค)}`
**เพิ่มประโยคเติมคำ:** เพิ่มใน `BLANKS` รูปแบบ `{u, s:'... ___ ...', a, o:[4 ตัวเลือก]}`

## ข้อจำกัด
- โหมดไมค์ในเกมแข่งรถใช้บน iPad/iPhone ไม่ได้ (Safari ไม่รองรับ SpeechRecognition) — ใช้โหมด “ฟังแล้วเลือก” แทน
- เสียงครูเป็นเสียงสังเคราะห์ของเครื่อง เสียงสระโดด ๆ อาจไม่เป๊ะเท่าครูจริง จึงสอนแบบ “เสียง–เสียง–คำ”
- ความคืบหน้าเก็บในเครื่อง (ไม่ซิงก์ข้ามอุปกรณ์)
