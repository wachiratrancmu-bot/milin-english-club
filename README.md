## วิธีเล่น

**บน iPad (แนะนำ)**
1. ส่งไฟล์ `Milin-English-Club.html` เข้า iPad (AirDrop / iCloud Drive / อีเมล)
2. เปิดด้วย **Safari** (ไม่ใช่ Chrome — เสียงอ่านจะไม่ทำงาน)
3. หมุน iPad เป็น **แนวนอน** แล้วแตะจอ 1 ครั้งเพื่อปลดล็อกเสียง (ข้อกำหนดของ iOS)
4. อยากให้เป็นไอคอนเหมือนแอป: ปุ่มแชร์ → **Add to Home Screen**

**อัปโหลดขึ้นเว็บเอง** — ไฟล์เป็น self-contained ไม่มี CDN ไม่มีไฟล์แนบ ลากขึ้นที่ไหนก็ได้:
Netlify Drop (netlify.com/drop) · GitHub Pages · Cloudflare Pages · Vercel — ลากไฟล์เดียวขึ้นไปแล้วใช้ได้ทันที

หน้าจอออกแบบบนขนาด **iPad แนวนอน 1194×834** แล้วย่อ/ขยายให้พอดีจอที่เปิดโดยอัตโนมัติ
หน้าตาจึงเหมือนกันทุกเครื่อง ทั้ง iPad คอม และบนเว็บ

## ระบบเสียง

- **ครูผู้หญิงเท่านั้น** — เลือกอัตโนมัติจาก Samantha / Karen / Moira / Zira ฯลฯ และกรองเสียงผู้ชายออก
  ชื่อเสียงที่ใช้แสดงบนแถบบน แตะเพื่อทดสอบ · เลือกเองได้ที่ ⚙️ ตั้งค่า → เสียงครู
- **โฟนิกส์ทั้งระบบ** — ทุกครั้งที่ครูออกเสียงคำจะเป็นลำดับ `c` → `at` → `c-at` → `cat` พร้อม IPA กำกับทุกเสียง
- **ปรับความเร็วได้ตลอดเวลา** — ปุ่ม 🐢 ช้ามาก / 🐇 ช้า / 🚶 ปกติ / ⚡ เร็ว อยู่บนแถบบน **เห็นได้ทุกหน้าจอ**
  เวลาหยุดระหว่างเสียงจะยืดตามความเร็วด้วย เด็กจะออกเสียงตามทัน · ปรับละเอียดได้ที่ ⚙️ ตั้งค่า
- ทุกเกมมีปุ่ม **🐢 ฟังทีละเสียง** และ **🔊 ฟังคำเต็ม**

## โครงสร้างไฟล์ (สำหรับแก้ต่อใน Claude Code)

ไฟล์เดียว ไม่มี build step ไม่มี dependency — แก้แล้วรีเฟรชได้เลย แบ่ง 7 ส่วน มีคอมเมนต์คั่น:

| ส่วน | อยู่ที่ | หน้าที่ |
|---|---|---|
| 1. CSS | `<style>` | สี ขนาด แอนิเมชัน (ตัวแปรสีอยู่ที่ `:root`) |
| 2. **CONTENT** | `FAMILIES` `STORIES` `DICT` `CHANTS` `SIGHT` `SCRAMBLE` `MATCH` `TRANSLATE` `SCENES` `RACE_WORDS` `MISSING` `CIRCLE` `SORTS` `YESNO` `PAINTS` `COLOUR_TASKS` `GAMES` | **เนื้อหาทั้งหมดอยู่ตรงนี้** เพิ่ม/แก้คำศัพท์ ประโยค คำแปล ได้โดยไม่ต้องแตะโค้ดเกม |
| 3. PHONICS ENGINE | `PHON` `pieces()` `WALL` | ตารางเสียง 72 รายการ: `key:['/IPA/','คำที่ให้ TTS อ่าน','ตัวอย่างคำ']` |
| 4. VOICE | `Voice` | เลือกครูผู้หญิง · `Voice.phonics()` คือหัวใจการออกเสียง |
| 5. APP CORE | `S` `render()` `ACT` `fitStage()` | state, router, event delegation, ย่อ/ขยายจอ |
| 6. GAMES | `VIEWS.xxx` + `ACT.xxx` | เกมละ 1 บล็อก |
| 7. BOOT | ท้ายไฟล์ | เริ่มระบบ + ปลดล็อกเสียงบน iOS |

**เพิ่มคำใหม่** → เพิ่ม `{w, on, th, emoji, sent, sentTh}` เข้า `words` ของตระกูลใน `FAMILIES`
(คำที่ rime ไม่ตรงกับชื่อตระกูล ใส่ `ri:'...'` เพิ่ม) ถ้าเป็นเสียงใหม่ ให้เพิ่มใน `PHON` ด้วย

**เพิ่มเรื่องใหม่** → เพิ่มใน `STORIES` แล้วเพิ่มคำศัพท์ลง `DICT` เพื่อให้แตะคำแล้วเห็นคำแปล

**เพิ่มเกมใหม่** → เพิ่มใน `GAMES` + `TITLES`, เขียน `VIEWS.ชื่อเกม`, เขียน `ACT.xxx` แล้วใส่ `data-act="xxx"` ใน HTML

## ข้อจำกัดที่ควรรู้

- **โหมดไมค์ในเกมแข่งรถใช้บน iPad ไม่ได้** — Safari บน iOS ยังไม่รองรับ `SpeechRecognition`
  ค่าเริ่มต้นจึงเป็นโหมด **“👂 ฟังแล้วเลือกคำ”** (มีตัวลวงเสียงใกล้เคียง เช่น cook / coke / kick)
  ถ้ากดโหมดไมค์บนเครื่องที่ไม่รองรับ ระบบจะสลับกลับให้เอง โหมดไมค์ใช้ได้บน Chrome บนคอม
  → ถ้าอยากได้การประเมินการออกเสียงจริงบน iPad ต้องต่อ API ภายนอก จุดเสียบคือฟังก์ชัน `judgeRace()`
- รูปประกอบใช้ emoji (ยกเว้นเกมระบายสีที่วาดเป็น SVG จริง) ถ้ามีภาพจริงส่งมาได้ ใส่แทนได้ที่ `SCENES` และฟิลด์ `emoji`
- ตัวอักษรใช้ฟอนต์ในเครื่อง (ไม่โหลดจากเน็ต) หน้าตาตัวอักษรจึงต่างกันเล็กน้อยระหว่าง iPad กับ Windows
